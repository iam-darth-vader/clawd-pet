# Clawd — питомец Claude Code для рабочего стола

Маленький оранжевый Clawd бегает по экрану за курсором, живёт своей жизнью и **злится, если в него тыкать**.

![Все состояния](docs/preview.png)

## Что умеет

- Бегает за мышкой и останавливается сбоку от курсора, не мешая кликать. Клики везде, кроме самого питомца, проходят сквозь него.
- Моргает, оглядывается, притопывает, потягивается. Если мышь долго не трогать, зевает и засыпает.
- При кликах злится всё сильнее: косится, краснеет, топает, машет кулачками, пыхтит паром, орёт. Если довести, обижается и отворачивается.
- Можно схватить и швырнуть: болтается, отскакивает от краёв экрана, у него кружится голова.
- Вылезает из-за панели при включении и ныряет за неё при выключении.
- Прячется, когда открыто полноэкранное окно, и когда выключен композитинг.
- Реплики в облачках можно выключить.

Вся анимация процедурная: пружины, физика шага и броска, частицы. Готовых кадров нет.

## Требования

- Linux, сессия **X11** с композитингом (проверено на KDE Plasma 6).
- Python 3.10+ и PySide6: `pip install --user PySide6`

## Запуск

```bash
python3 clawd.py            # запустить; повторный запуск зовёт питомца к курсору
python3 clawd.py --toggle   # выпустить / спрятать
python3 clawd.py --quit     # выключить
python3 clawd.py --install  # ярлык в меню приложений
```

Клик по значку в трее выпускает или прячет Clawd. Правый клик по нему или по питомцу открывает меню: размер, «Ходить за мышкой», «Реплики», прятаться в полноэкранных окнах, автозапуск.

Настройки хранятся в `~/.config/clawd-pet/config.json`.
